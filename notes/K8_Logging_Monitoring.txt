# K8_Logging_Monitoring
= = = = = = = = = = = =
Enable Metric Server -

> minikube addons enable metrics-server    <- One time activity

Then hit the command to know the node and pod status.

[osboxes@osboxes metrics-server]$ kubectl top node
NAME       CPU(cores)   CPU%   MEMORY(bytes)   MEMORY%   
minikube   239m         11%    911Mi           32%       
[osboxes@osboxes metrics-server]$ kubectl top pod
NAME                              CPU(cores)   MEMORY(bytes)   
hello-minikube-65dc654df9-2w94n   0m           5Mi             
[osboxes@osboxes metrics-server]$ kubectl top pods
NAME                              CPU(cores)   MEMORY(bytes)   
hello-minikube-65dc654df9-2w94n   0m           5Mi             
[osboxes@osboxes metrics-server]$ minikube addons enable metrics-server
